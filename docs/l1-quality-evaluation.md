# L1 提炼质量：初步评估

2026-10-30 使用 DeepSeek Flash 和合成对话评估内部 L1 提炼。样本见 `tests/fixtures/l1-quality.json`，运行器为 `scripts/eval-l1.cjs`：读取标准输入中的 API 密钥、使用临时数据库并在退出时清理。结果仅用于分析提炼，不代表召回质量或真实用户数据的表现。

## 提示词调整

旧提示词允许空记忆，但没有说明哪些场景值得保留。新版补充个人、工作、代码、创作和研究场景，要求保留主体、作品或项目语境、限定条件、时间和未决状态，避免将建议当成已确认决策，并尽量使用来源语言。模型原始响应为空白时现在报告 `MODEL_OUTPUT_EMPTY`；合法的 `{"memories":[]}` 仍表示模型判断没有可提炼记忆，无法仅凭格式判断该判断是否正确。

## 结果

| 样本与协议                    | 调用 | 应产生记忆的调用 | 成功但为空 |         其他失败 | 寒暄产生记忆 |
| ----------------------------- | ---: | ---------------: | ---------: | ---------------: | -----------: |
| 旧提示词，开发样本，Chat      |   20 |               18 |          1 |                0 |          0/2 |
| 新提示词，开发样本，Chat      |   20 |               18 |          0 | 1 次网络结果未知 |          0/2 |
| 新提示词，独立样本，Responses |    8 |                6 |          0 | 1 次输出校验失败 |          0/2 |

开发样本是 9 个正例和 1 个寒暄，各运行两次；独立样本是 3 个正例和 1 个寒暄，各运行两次。旧提示词将同一个虚构设定在两次调用中分别提炼为记忆和空数组。新版在这两次调用中均产生了记忆，中文开发样本的成功输出均使用中文。样本小且模型有随机性，不能由此推断总体准确率或证明问题消失。

独立样本中一次输出未通过 Service 校验，原始输出当时未采集，无法确定根因；对同一时间样本另外运行 5 次均成功，不等于问题已经解决。运行器现会在 `MODEL_OUTPUT_INVALID` 时显示合成样本的模型输出，以便后续定位。

人工阅读发现新版仍可能把“准备使用”改写成“确定使用”，或在引用助手建议及用户未确认时遗漏支持“未确认”的来源 ID；另一次把参加摄影展推断为摄影兴趣。Service 只能验证 ID 属于输入批次，不能验证来源是否足以支持结论。检查词仅用于发现明显漏项，不能判断主体、语义、来源或事实正确，不能作为准确率。

模型 API 的调用成本、延迟及错误率随网络、模型配置与输入变化；这组短输入不能推断实际工作负载。下一轮应扩大合成与经授权真实样本，逐条人工标注遗漏、错误事实、来源、限定条件和抽象/线索；空白响应、合法空数组、校验失败与网络结果未知分别统计。上线或自动处理前需要确定评测集及可接受标准。
