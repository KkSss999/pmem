# v0.5 Productization Beta Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn pmem v0.4 into an installable, understandable, verifiable v0.5 Beta CLI product.

**Architecture:** Keep the v0.4 runtime unchanged unless product-readiness E2E reveals bugs. Productization work is organized around public entry documents, package metadata, install/real-workflow E2E scripts, error UX, and release artifacts.

**Tech Stack:** TypeScript, Commander, Node.js `node:test`, npm package tarballs, Markdown docs.

---

### Task 3: E2E Scripts

**Files:**
- Create: `scripts/e2e-install-smoke.sh`
- Create: `scripts/e2e-real-workflow.sh`
- Modify: `package.json`

- [ ] **Step 1: Add install smoke script**

Script should build, pack, install the tarball into a temporary npm prefix, and run `pmem --version` and `pmem --help`.

- [ ] **Step 2: Add real workflow script**

Script should create a temp project, initialize pmem, write a source file and module card, rebuild, recall, ask, change the source file, run status, mark dirty, suggest update, confirm update, and verify.

- [ ] **Step 3: Add npm scripts**

Add:

```json
{
  "test:e2e:install": "bash scripts/e2e-install-smoke.sh",
  "test:e2e:workflow": "bash scripts/e2e-real-workflow.sh"
}
```

- [ ] **Step 4: Run E2E**

Run:

```bash
npm run test:e2e:install
npm run test:e2e:workflow
```

Expected: both scripts pass on a clean working tree.
